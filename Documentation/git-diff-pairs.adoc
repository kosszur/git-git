git-diff-pairs(1)
=================

NAME
----
git-diff-pairs - Megadott blob-párok tartalmának és módjának összehasonlítása

SYNOPSIS
--------
[synopsis]
git diff-pairs -z [<diff-options>]

DESCRIPTION
-----------
A standard bemeneten megadott fájlpárok változásait mutatja meg. E parancs bemenetének
a NUL-lel lezárt nyers kimeneti formátumban kell lennie, ahogy azt az olyan parancsok
állítják elő, mint a `git diff-tree -z -r --raw`. Alapértelmezés szerint a kiírt diffek
patch formátumban kerülnek kiszámításra és megjelenítésre, amikor a standard bemenet lezárul.

Egyetlen NUL bájt írható a standard bemenetre a nyers bemeneti sorok között, hogy az addigi
pontig kiszámítsa a fájlpár-diffeket ahelyett, hogy megvárná a standard bemenet lezárulását.
A kimenetre szintén egy NUL bájt kerül, hogy elválassza egymástól a diffek e csoportjait.

E parancs használata lehetővé teszi, hogy a hagyományos diff-folyamat külön szakaszokra
bontható legyen, amelyekben a `diff-pairs` a kimeneti fázisként működik. Más parancsok,
például a `diff-tree`, szolgálhatnak frontendként a bemenetként használt nyers diff
formátum kiszámításához.

Ahelyett, hogy a diffeket egy lépésben a `git diff-tree -p -M` paranccsal számítanánk ki,
a `diff-tree` a blob-diffek nélkül is ki tudja számítani a fájlpárokat és az átnevezési
információkat. Ez a kimenet átadható a `diff-pairs`-nak, hogy előállítsa a mögöttes
blob-diffeket, ahogy azt a következő példa is mutatja:

-----------------------------
git diff-tree -z -r -M $a $b |
git diff-pairs -z
-----------------------------

A fa-diff előzetes, átnevezési információval együtt történő kiszámítása lehetővé teszi,
hogy a `diff-pairs` patch kimenete akár több meghívás során, fokozatosan kerüljön
kiszámításra.

A `diff-pairs` jelenleg nem támogatja a pathspeceket. A pathspec szerinti szűkítést a
bemenetként használt nyers diffeket előállító, előzetes (upstream) parancsnak kell
elvégeznie.

A fa (tree) objektumok bemenetként jelenleg nem támogatottak, és elutasításra kerülnek.

A `diff-pairs` bemenetében a rövidített objektumazonosítók nem támogatottak. A kiírt
objektumazonosítók a `--abbrev` opcióval rövidíthetők.
