git-credential-cache{litdd}daemon(1)
====================================

NAME
----
git-credential-cache--daemon - Felhasználói hitelesítő adatok átmeneti tárolása a memóriában

SYNOPSIS
--------
[verse]
'git credential-cache{litdd}daemon' [--debug] <socket-path>

DESCRIPTION
-----------

NOTE: Valószínűleg nem akarod ezt a parancsot saját kezűleg meghívni; ez
automatikusan elindul, amikor a linkgit:git-credential-cache[1] parancsot
használod.

Ez a parancs a `<socket-path>` által megadott Unix domain socketen
figyel a `git-credential-cache` kliensekre. A kliensek hitelesítő
adatokat tárolhatnak és kérhetnek le. Minden hitelesítő adatot a kliens
által megadott időkorlátig őriz meg; amint egyetlen hitelesítő adatot
sem tart már, a daemon leáll.

Ha a `--debug` opció meg van adva, a daemon nem zárja le a stderr
adatfolyamát, és a kliensekre való figyelés megkezdése után is
kiírhat rá további diagnosztikai üzeneteket.

GIT
---
A linkgit:git[1] csomag része
