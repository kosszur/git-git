* `0` vagy `false` - Letiltja a célt.
* `1` vagy `true` - A `STDERR`-re ír.
* `[2-9]` - A már megnyitott fájlleíróba ír.
* `<absolute-pathname>` - A fájlba ír hozzáfűzés módban. Ha a cél már
létezik és egy könyvtár, a nyomkövetési adatok a megadott könyvtár
alatti fájlokba kerülnek (folyamatonként egybe).
* `af_unix:[<socket-type>:]<absolute-pathname>` - Egy Unix
DomainSocketbe ír (olyan platformokon, amelyek támogatják ezt). A
socket típusa lehet `stream` vagy `dgram`; ha nincs megadva, a Git
mindkettőt megpróbálja.
