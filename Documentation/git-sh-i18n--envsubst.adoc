git-sh-i18n{litdd}envsubst(1)
=============================

NAME
----
git-sh-i18n--envsubst - A Git saját envsubst(1) programja i18n tartalékmegoldásokhoz

SYNOPSIS
--------
[verse]
eval_gettext () {
	printf "%s" "$1" | (
		export PATH $('git sh-i18n{litdd}envsubst' --variables "$1");
		'git sh-i18n{litdd}envsubst' "$1"
	)
}

DESCRIPTION
-----------

Ez nem egy olyan parancs, amelyet a végfelhasználó futtatni akarna.
Soha. Ez a dokumentáció azoknak szól, akik a plumbing szkripteket
tanulmányozzák, és/vagy újakat írnak.

A 'git sh-i18n{litdd}envsubst' a Git leegyszerűsített másolata a GNU
gettext csomaggal érkező GNU `envsubst(1)` programnak. Belsőleg a
linkgit:git-sh-i18n[1] használja az `eval_gettext` függvénynek átadott
változók behelyettesítésére.

Nincs semmilyen ígéret az interfészre vonatkozóan, sem arra, hogy ez
a program nem tűnik el figyelmeztetés nélkül a Git következő
verziójában. Ne használd.
