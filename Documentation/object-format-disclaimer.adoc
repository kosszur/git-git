Megjegyzés: jelenleg nincs interoperabilitás az SHA-256 és az SHA-1
repository-k között.

Korábban azt jeleztük, hogy az SHA-256 repository-knak később
visszafelé nem kompatibilis változtatásokra lehet szükségük, amikor
bevezetjük az ilyen interoperabilitási funkciókat. Ma már csak
kompatibilis változtatásokra számítunk. Továbbá, ha ilyen változtatások
mégis szükségesnek bizonyulnak, várható, hogy a mai Git-tel létrehozott
SHA-256 repository-k a Git jövőbeli verzióival is használhatók lesznek
adatvesztés nélkül.
