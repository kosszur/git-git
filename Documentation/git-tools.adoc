Git eszközök
============

Amikor a Git még fiatal volt, a harmadik féltől származó Git-kapcsolódó
eszközöket keresők magához a Git projekthez fordultak, hogy megtalálják
őket, ezért itt tartottunk fenn egy ilyen eszközlistát. Manapság azonban
a keresőmotorok sokkal hatékonyabban töltik be ezt a szerepet, ezért ez
a kézzel karbantartott lista visszavonásra került.

Lásd még a `contrib/` területet, valamint a Git wikit:
https://git.wiki.kernel.org/index.php/InterfacesFrontendsAndTools
