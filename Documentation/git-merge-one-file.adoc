git-merge-one-file(1)
=====================

NAME
----
git-merge-one-file - A git-merge-index-szel használandó szabványos segédprogram


SYNOPSIS
--------
[verse]
'git merge-one-file'

DESCRIPTION
-----------
Ez a 'git merge-index'-szel használandó szabványos segédprogram,
amely a 'git read-tree -m'-mel elvégzett triviális merge utáni
merge-et oldja fel.

GIT
---
A linkgit:git[1] csomag része
