git-show-index(1)
=================

NAME
----
git-show-index - Megjeleníti a csomagolt archívum indexét


SYNOPSIS
--------
[verse]
'git show-index' [--object-format=<hash-algorithm>] < <pack-idx-file>


DESCRIPTION
-----------
Beolvassa egy Git packfile `.idx` fájlját (amelyet a
linkgit:git-pack-objects[1] vagy a linkgit:git-index-pack[1] hozott
létre) a standard bemenetről, és kiírja a tartalmát. A kimenet
soronként egy objektumból áll, minden sor két vagy három, szóközzel
elválasztott oszlopot tartalmaz:

  - az első oszlop az objektum bájtokban mért eltolása a hozzá
    tartozó packfile-on belül

  - a második oszlop az objektum objektumazonosítója

  - ha az indexverzió 2 vagy magasabb, a harmadik oszlop az
    objektumadatok CRC32-ét tartalmazza

Az objektumok abban a sorrendben kerülnek kiírásra, amilyen
sorrendben megtalálhatók az indexfájlban, amelynek (egy helyesen
felépített fájlban) objektumazonosító szerint rendezettnek kell
lennie.

Vedd figyelembe, hogy egy packfile-ról több információt is kaphatsz a
linkgit:git-verify-pack[1] meghívásával. Azonban, mivel ez a parancs
csak magát az indexfájlt veszi figyelembe, gyorsabb és rugalmasabb is.

OPTIONS
-------

--object-format=<hash-algorithm>::
	Megadja az indexfájl objektumformátumát (hash-algoritmusát).
	Az érvényes értékek a 'sha1' és (ha engedélyezve van) a
	'sha256'. Az alapértelmezett az aktuális repository algoritmusa
	(amelyet az `extensions.objectFormat` állít be), vagy 'sha1',
	ha nincs érték beállítva, vagy repository-n kívül vagyunk.
