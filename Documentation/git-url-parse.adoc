git-url-parse(1)
================

NAME
----
git-url-parse - Feldolgozza és kinyeri a git URL-ek összetevőit

SYNOPSIS
--------
[synopsis]
git url-parse [-c <component>] [--] <url>...

DESCRIPTION
-----------

A Git sokféle módon támogatja az URL-ek megadását, ezek közül néhány
nem szabványos. Például a git támogatja az scp-stílusú
[user@]host:[path] formátumot. Ez a parancs megkönnyíti a
git URL-ekkel való interoperabilitást azáltal, hogy lehetővé teszi
minden git URL összetevőinek feldolgozását és kinyerését.

Minden szintaktikailag érvényes URL feldolgozásra kerül, még akkor
is, ha a séma nem olyan, amelyet a git a letöltéshez vagy a pusholáshoz
támogat.

OPTIONS
-------

`-c <component>`::
`--component <component>`::
	Kinyeri a _<component>_ összetevőt a megadott Git URL-ekből.
	A _<component>_ a következők egyike lehet:
	`scheme`, `user`, `password`, `host`, `port`, `path`.

OUTPUT
------

Ha a `--component` meg van adva, minden URL kért összetevője saját
sorában kerül kiírásra, abban a sorrendben, ahogy az URL-ek meg
lettek adva. Ha az URL-nek nincs ilyen összetevője (például egy port
egy olyan URL-ben, amely nem ad meg ilyet), a helyén egy üres sor
kerül kiírásra.

Ha a `--component` nincs megadva, nem keletkezik kimenet. A kilépési
állapot nulla, ha minden URL sikeresen feldolgozásra kerül, egyébként
nem nulla, ami lehetővé teszi, hogy a parancsot tisztán
validátorként használd.

EXAMPLES
--------

* A hosztnév kiírása:
+
------------
$ git url-parse --component host https://example.com/user/repo
example.com
------------

* Az útvonal kiírása:
+
------------
$ git url-parse --component path https://example.com/user/repo
/user/repo
$ git url-parse --component path example.com:~user/repo
~user/repo
$ git url-parse --component path example.com:user/repo
/user/repo
------------

* URL-ek érvényesítése bármilyen kimenet nélkül:
+
------------
$ git url-parse https://example.com/user/repo example.com:~user/repo
------------
