git-verify-tag(1)
=================

NAME
----
git-verify-tag - Ellenőrzi a tagek GPG-aláírását

SYNOPSIS
--------
[synopsis]
git verify-tag [-v | --verbose] [--format=<format>] [--raw] <tag>...

DESCRIPTION
-----------
Érvényesíti a `git tag`-gel létrehozott gpg-aláírást a parancssorban
felsorolt tag-objektumokban.

OPTIONS
-------
`--raw`::
	A nyers gpg-státuszkimenetet a standard hibakimenetre írja ki a
	szokásos, emberi olvasásra szánt kimenet helyett.

`-v`::
`--verbose`::
	Kiírja a tag-objektum tartalmát az érvényesítés előtt.
