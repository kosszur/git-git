git-get-tar-commit-id(1)
========================

NAME
----
git-get-tar-commit-id - Kinyeri a commit ID-t egy git-archive-dzsal létrehozott archívumból


SYNOPSIS
--------
[verse]
'git get-tar-commit-id'


DESCRIPTION
-----------

Beolvas egy 'git archive'-vel létrehozott tar archívumot a standard
bemenetről, és kinyeri a benne tárolt commit ID-t. Csak a bemenet
első 1024 bájtját olvassa be, így a futásideje nem függ jelentősen a
tar archívum méretétől.

Ha nem talál commit ID-t, a 'git get-tar-commit-id' csendben, 1-es
visszatérési kóddal lép ki. Ez akkor fordulhat elő, ha az archívumot
nem a 'git archive'-vel hozták létre, vagy ha a 'git archive' első
paramétere egy fa ID volt commit ID vagy tag helyett.
