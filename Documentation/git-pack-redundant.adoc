git-pack-redundant(1)
=====================

NAME
----
git-pack-redundant - Redundáns packfile-okat keres


SYNOPSIS
--------
[verse]
'git pack-redundant' [--verbose] [--alt-odb] (--all | <pack-filename>...)

WARNING
-------
A `git pack-redundant` elavulttá vált, és eltávolításra van ütemezve
a Git egy jövőbeli verziójában. Mivel csak egész duplikált packeket
tud eltávolítani, egyedi duplikált objektumokat nem, általában nem
hasznos eszköz a repository méretének csökkentésére. Jobban jársz, ha
ehelyett a `git gc`-t használod, amely az objektumokat egy új packba
teszi, eltávolítva a duplikátumokat.

A `pack-redundant` futtatása a `--i-still-use-this` kapcsoló nélkül
ebben a kiadásban sikertelen lesz. Ha úgy gondolod, van olyan
felhasználási eseted, amelyre a `pack-redundant` jobban alkalmas, és
ellenzed ezt az eltávolítást, kérjük, lépj kapcsolatba a Git
levelezőlistával a git@vger.kernel.org címen. A listáról további
információ a https://git-scm.com/community oldalon érhető el.

DESCRIPTION
-----------
Ez a program kiszámítja, hogy a repository-dban mely packek
redundánsak. A kimenet alkalmas arra, hogy `xargs rm`-be csöveztesd,
ha a repository gyökerében vagy.

A 'git pack-redundant' egy objektumlistát fogad el a standard
bemeneten. A megadott objektumok figyelmen kívül maradnak annak
ellenőrzésekor, hogy mely packekre van szükség. Ez hasznossá teszi a
következő parancsot, ha el nem érhető objektumokat tartalmazó
packeket szeretnél eltávolítani.

git fsck --full --unreachable | cut -d ' ' -f3 | \
git pack-redundant --all | xargs rm

OPTIONS
-------


--all::
	Minden packet feldolgoz. A parancssorban megadott fájlnevek
	figyelmen kívül maradnak.

--alt-odb::
	Nem követeli meg, hogy az alternatív objektumadatbázis (odb)
	könyvtárakból származó packekben jelen lévő objektumok a
	helyi packekben is jelen legyenek.

--verbose::
	Néhány statisztikát ír ki a stderr-re. Kis
	teljesítménybüntetéssel jár.
