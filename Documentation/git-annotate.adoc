git-annotate(1)
===============

NAME
----
git-annotate - Fájlsorok annotálása commit-információval

SYNOPSIS
--------
[verse]
'git annotate' [<options>] [<rev-opts>] [<rev>] [--] <file>

DESCRIPTION
-----------
A megadott fájl minden sorát annotálja az adott sort bevezető commit
információjával. Opcionálisan egy megadott revíziótól kezdve annotál.

Az egyetlen különbség e parancs és a linkgit:git-blame[1] között, hogy
kissé eltérő kimeneti formátumot használnak, és ez a parancs csak a
visszafelé kompatibilitás miatt létezik, hogy támogassa a meglévő
szkripteket, és ismerősebb parancsnevet adjon a más SCM-rendszerekből
érkezőknek.
