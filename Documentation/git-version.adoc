git-version(1)
==============

NAME
----
git-version - Megjeleníti a Git verzióinformációit

SYNOPSIS
--------
[verse]
'git version' [--build-options]

DESCRIPTION
-----------
Opciók megadása nélkül a 'git' verziója íródik ki a standard kimenetre.

Vedd figyelembe, hogy a `git --version` azonos a `git version`-nel,
mert az előbbi belsőleg átalakul az utóbbivá.

OPTIONS
-------
--build-options::
	Diagnosztikai célból további információkat is tartalmaz arról,
	hogyan lett a git felépítve.
+
Az SHA-1 és SHA-256 algoritmusok megvalósításához használt könyvtárak
`SHA-1: <option>` és `SHA-256: <option>` formában jelennek meg. Vedd
figyelembe, hogy az `SHA1_APPLE`, `SHA1_OPENSSL` és `SHA1_BLK` SHA-1
opciók nem használnak ütközésészlelő algoritmust, ezért sérülékenyek
lehetnek az ismert SHA-1-ütközéses támadásokkal szemben. Ha egy
gyorsabb, ütközésészlelés nélküli SHA-1-megvalósítást használnak
kizárólag nem kriptográfiai célokra, az algoritmus
`non-collision-detecting-SHA-1: <option>` formában jelenik meg.
