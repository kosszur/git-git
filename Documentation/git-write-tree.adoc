git-write-tree(1)
=================

NAME
----
git-write-tree - Fa-objektumot hoz létre az aktuális indexből


SYNOPSIS
--------
[synopsis]
git write-tree [--missing-ok] [--prefix=<prefix>/]

DESCRIPTION
-----------
Egy fa-objektumot hoz létre az aktuális index felhasználásával. Az új
fa-objektum neve a standard kimenetre íródik ki.

Az indexnek teljesen merge-elt állapotban kell lennie.

Koncepcionálisan a `git write-tree` szinkronizálja (sync()) az
aktuális index tartalmát egy fa-fájlkészletbe.
Ahhoz, hogy ez megegyezzen azzal, ami éppen most a könyvtáradban van,
egy `git update-index` fázist kell végrehajtanod, mielőtt a
`git write-tree`-t futtatod.


OPTIONS
-------
`--missing-ok`::
	Normál esetben a `git write-tree` biztosítja, hogy a könyvtár
	által hivatkozott objektumok léteznek az objektumadatbázisban.
	Ez az opció kikapcsolja ezt az ellenőrzést.

`--prefix=<prefix>/`::
	Egy olyan fa-objektumot ír, amely a _<prefix>_ alkönyvtárat
	reprezentálja. Ez felhasználható a fa-objektum kiírására egy
	olyan alprojekthez, amely a megnevezett alkönyvtárban van.
