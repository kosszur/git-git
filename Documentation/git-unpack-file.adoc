git-unpack-file(1)
==================

NAME
----
git-unpack-file - Létrehoz egy ideiglenes fájlt egy blob tartalmával



SYNOPSIS
--------
[verse]
'git unpack-file' <blob>

DESCRIPTION
-----------
Létrehoz egy fájlt, amely a sha1-gyel megadott blob tartalmát tárolja.
Az ideiglenes fájl nevét a következő formátumban adja vissza:
	.merge_file_XXXXX

OPTIONS
-------
<blob>::
	Blob azonosítónak kell lennie

GIT
---
A linkgit:git[1] csomag része
