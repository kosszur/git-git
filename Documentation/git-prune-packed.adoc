git-prune-packed(1)
===================

NAME
----
git-prune-packed - Eltávolítja azokat a felesleges objektumokat, amelyek már packfile-okban vannak


SYNOPSIS
--------
[verse]
'git prune-packed' [-n | --dry-run] [-q | --quiet]


DESCRIPTION
-----------
Ez a program átvizsgálja a `$GIT_OBJECT_DIRECTORY`-t minden olyan
objektumért, amely jelenleg egyaránt megtalálható egy packfile-ban és
a független objektum-könyvtárakban is.

Minden ilyen felesleges objektum eltávolításra kerül.

Egy pack objektumok gyűjteménye, egyenként tömörítve, delta-
tömörítéssel, egyetlen fájlban tárolva, egy hozzá tartozó index-
fájllal.

A packek a terhelés csökkentésére szolgálnak a tükörrendszereken,
biztonsági mentési motorokon, lemeztárolón stb.


OPTIONS
-------
-n::
--dry-run::
        Ténylegesen nem távolít el egyetlen objektumot sem, csak
        megmutatja azokat, amelyeket eltávolított volna.

-q::
--quiet::
	Elnyomja a folyamatjelzőt.
