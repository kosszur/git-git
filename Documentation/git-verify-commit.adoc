git-verify-commit(1)
====================

NAME
----
git-verify-commit - Ellenőrzi a commitok GPG-aláírását

SYNOPSIS
--------
[synopsis]
git verify-commit [-v | --verbose] [--raw] <commit>...

DESCRIPTION
-----------
Érvényesíti a `git commit -S`-sel létrehozott GPG-aláírást a
parancssorban megadott commit-objektumokon.

OPTIONS
-------
`--raw`::
	A nyers gpg-státuszkimenetet a standard hibakimenetre írja ki a
	szokásos, emberi olvasásra szánt kimenet helyett.

`-v`::
`--verbose`::
	Kiírja a commit-objektum tartalmát az érvényesítés előtt.
