git-init-db(1)

NAME
----
git-init-db - Létrehoz egy üres Git repository-t


SYNOPSIS
--------
[verse]
'git init-db' [-q | --quiet] [--bare] [--template=<template-directory>] [--separate-git-dir <git-dir>] [--shared[=<permissions>]]


DESCRIPTION
-----------

Ez a linkgit:git-init[1] szinonimája. Kérjük, nézd meg annak a
parancsnak a dokumentációját.

GIT
