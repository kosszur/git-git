gitrevisions(7)
===============

NAME
----
gitrevisions - Revíziók és tartományok megadása a Git számára

SYNOPSIS
--------
gitrevisions


DESCRIPTION
-----------

Sok Git-parancs vesz fel revízió-paramétereket argumentumként. A
parancstól függően ezek egy konkrét commitot jelölnek, vagy a
revíziógráfot bejáró parancsok esetén (mint a linkgit:git-log[1])
minden olyan commitot, amely elérhető abból a commitból. A
revíziógráfot bejáró parancsoknál egy revíziótartomány is explicit
módon megadható.

Emellett néhány Git-parancs (mint a linkgit:git-show[1] és a
linkgit:git-push[1]) olyan revízió-paramétereket is elfogadhat,
amelyek nem commitokat, hanem más objektumokat jelölnek, pl. blobokat
("fájlok") vagy fákat ("fájlok könyvtárai").
