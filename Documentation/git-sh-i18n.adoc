git-sh-i18n(1)
==============

NAME
----
git-sh-i18n - A Git i18n beállító kódja shell szkriptekhez

SYNOPSIS
--------
[verse]
'. "$(git --exec-path)/git-sh-i18n"'

DESCRIPTION
-----------

Ez nem egy olyan parancs, amelyet a végfelhasználó futtatni akarna.
Soha. Ez a dokumentáció azoknak szól, akik a porcelain-szerű
szkripteket tanulmányozzák, és/vagy újakat írnak.

A 'git sh-i18n szkriptrészlet arra lett tervezve, hogy a Git
shell szkriptben megvalósított porcelain programjai forrásként
(a `.`-tal) beolvassák. Wrappereket biztosít a `gettext.sh`
szkripten keresztül elérhető GNU `gettext` és `eval_gettext`
függvényekhez, és átengedő tartalékmegoldásokat biztosít azokon a
rendszereken, amelyeken nincs GNU gettext.

FUNCTIONS
---------

gettext::
	Jelenleg egy üres, átengedő függvény, amely a `printf(1)`
	körüli wrapperként van megvalósítva. Egy későbbi verzióban
	valódi gettext-megvalósítással lesz felváltva.

eval_gettext::
	Jelenleg egy üres, átengedő függvény, amely a `printf(1)`
	körüli wrapperként van megvalósítva, a linkgit:git-sh-i18n{litdd}envsubst[1]
	segédprogram által kifejtett változókkal. Egy későbbi verzióban
	valódi gettext-megvalósítással lesz felváltva.
