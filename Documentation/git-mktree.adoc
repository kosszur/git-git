git-mktree(1)
=============

NAME
----
git-mktree - Fa-objektumot épít ls-tree formátumú szövegből


SYNOPSIS
--------
[verse]
'git mktree' [-z] [--missing] [--batch]

DESCRIPTION
-----------
Beolvassa a standard bemenetet nem rekurzív `ls-tree` kimeneti
formátumban, és létrehoz egy fa-objektumot. A fabejegyzések
sorrendjét a mktree normalizálja, így a bemenet előzetes rendezése
nem szükséges. A létrehozott fa-objektum objektumneve a standard
kimenetre íródik ki.

OPTIONS
-------
-z::
	Ehelyett a NUL-lal lezárt `ls-tree -z` kimenetet olvassa be.

--missing::
	Engedélyezi a hiányzó objektumokat. Az alapértelmezett
	viselkedés (ezen opció nélkül) az, hogy ellenőrzi, hogy minden
	fabejegyzés hash-e egy létező objektumot azonosít. Ez az opció
	nincs hatással a gitlink-bejegyzések (más néven "submodule-ok")
	kezelésére, amelyeknek mindig megengedett a hiánya.

--batch::
	Lehetővé teszi több fa-objektum felépítését kilépés előtt.
	Minden fát egyetlen üres sor választ el. A záró újsor
	opcionális. Megjegyzés: ha a `-z` opciót használod, a sorok
	NUL-lal záródnak.
