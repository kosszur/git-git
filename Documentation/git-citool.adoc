git-citool(1)
=============

NAME
----
git-citool - Grafikus alternatíva a git-commithoz

SYNOPSIS
--------
[verse]
'git citool'

DESCRIPTION
-----------
Egy Tcl/Tk-alapú grafikus felület a módosított fájlok áttekintéséhez,
az indexbe való stage-eléséhez, a commit-üzenet beírásához és az új
commit rögzítéséhez az aktuális branch-en. Ez a felület alternatívát
kínál a kevésbé interaktív 'git commit' programhoz képest.

A 'git citool' valójában a `git gui citool` egy szabványos aliasa.
A további részletekért lásd: linkgit:git-gui[1].

---
