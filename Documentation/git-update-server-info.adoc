git-update-server-info(1)
=========================

NAME
----
git-update-server-info - Frissíti a kiegészítő info-fájlt, hogy segítse a "dumb" szervereket


SYNOPSIS
--------
[verse]
'git update-server-info' [-f | --force]

DESCRIPTION
-----------
Egy "dumb" szervernek, amely nem generál packeket menet közben,
rendelkeznie kell néhány kiegészítő információs fájllal a
$GIT_DIR/info és a $GIT_OBJECT_DIRECTORY/info könyvtárakban, hogy
segítse a kliensek felfedezni, milyen referenciák és packek vannak a
szerveren. Ez a parancs generálja az ilyen kiegészítő fájlokat.

OPTIONS
-------
-f::
--force::
	Az info-fájlokat a nulláról frissíti.

OUTPUT
------

Jelenleg a parancs a következő fájlokat frissíti. A rendeltetésük
leírásáért lásd a linkgit:gitrepository-layout[5]-öt:

* objects/info/packs

* info/refs

GIT
---
A linkgit:git[1] csomag része
