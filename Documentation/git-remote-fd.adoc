git-remote-fd(1)
================

NAME
----
git-remote-fd - Visszairányítja a "smart" átviteli adatfolyamot a hívónak

SYNOPSIS
--------
"fd::<infd>[,<outfd>][/<anything>]" (URL-ként)

DESCRIPTION
-----------
Ez a segédprogram a megadott fájlleírókat használja egy távoli
Git-szerverhez való kapcsolódáshoz. Nem a végfelhasználóknak szól,
hanem a git fetch, push vagy archive parancsot hívó programoknak és
szkripteknek.

Ha csak az <infd> van megadva, feltételezi, hogy egy távoli
Git-szerverhez (git-upload-pack, git-receive-pack vagy
git-upload-archive) kapcsolódó kétirányú socketről van szó. Ha mind
az <infd>, mind az <outfd> meg van adva, feltételezi, hogy egy távoli
Git-szerverhez kapcsolódó pipe-okról van szó (az <infd> a bejövő,
az <outfd> a kimenő pipe).

Feltételezi, hogy minden kézfogási (handshake) eljárás már
befejeződött (mint például a szolgáltatáskérés elküldése a
git://-hoz), mielőtt ez a segédprogram elindul.

Az <anything> bármilyen string lehet. Figyelmen kívül marad. Arra
szolgál, hogy információt adjon a felhasználónak az URL-ben, arra az
esetre, ha az az URL valamilyen kontextusban megjelenik.

ENVIRONMENT VARIABLES
---------------------
GIT_TRANSLOOP_DEBUG::
	Ha be van állítva, hibakeresési információkat ír ki a
	különböző olvasásokról/írásokról.

EXAMPLES
--------
`git fetch fd::17 master`::
	Letölti a mastert, a #17-es fájlleírót használva a
	git-upload-pack-kel való kommunikációhoz.

`git fetch fd::17/foo master`::
	Ugyanaz, mint fent.

`git push fd::7,8 master (URL-ként)`::
	Pusholja a mastert, a #7-es fájlleírót használva a
	git-receive-packből való adatolvasáshoz, és a #8-as
	fájlleírót az ugyanabba a szolgáltatásba való íráshoz.

`git push fd::7,8/bar master`::
	Ugyanaz, mint fent.
